# Nitro IA — Landing Page

Site estático pronto para deploy no Vercel.

## Estrutura
- `index.html` — landing principal
- `termos/` — Termos de Serviço
- `privacidade/` — Política de Privacidade
- `cancelamento-e-reembolso/` — Política de Cancelamento e Reembolso
- `assets/` — imagens, CSS e JS
- `vercel.json` — configuração de headers e URLs

## Deploy no monorepo

Este site vive em `sites/nitro-ia` dentro do repositório `vortex-properties/nitro-ia-sites`.

Na Vercel, use:

```text
Root Directory: sites/nitro-ia
Framework Preset: Other / Static
Build Command: vazio
```
